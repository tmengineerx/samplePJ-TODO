# samplePJ-TODO テスト仕様書

## テスト概要

- 対象：samplePJ-TODO（ログイン機能付きTODO管理アプリ）
- テスト方法：手動での結合テスト（実際にブラウザを操作して確認）
- エビデンス：各テスト項目に対応するスクリーンショットを `screenshots/` フォルダに格納し、ファイル名を「エビデンス」列に記載する

## 実施状況について

このテストは研修の必須課題ではなく、提出前の品質確認として自発的に実施したもの。No.1〜9まで実施し、全てOK。No.10以降は、提出タイミングの都合により今回は未実施（教育担当と相談の上、現状で提出しレビューを受ける方針とした）。

## 補足：No.4実施中に発生した環境トラブル

No.4実施中に `FATAL: データベースシステムはリカバリモードです` が発生。原因はアプリのコードではなく、**PostgreSQLの古いプロセス（PID）がサービス上は「停止」表示のまま裏で残り続け、ポート5432とロックファイル（`postmaster.pid`）を掴んでいたこと**。該当プロセスを終了し、`postmaster.pid` を削除した上でサービスを再開して復旧した。以降のテストへの影響は無い。

## 実施手順

1. 上から順に番号通りにテストを実施する
2. 各テスト項目の操作をしたらスクリーンショットを撮り、`screenshots/` フォルダに `No番号_内容.png`（例：`01_top画面.png`）の形式で保存する
3. 「結果」列に OK / NG を記入する
4. 「エビデンス」列に保存したファイル名を記入する
5. NGがあれば、そこで一旦立ち止まって原因を確認する
